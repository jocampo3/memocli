# Memo

A simple CLI tool for managing reminders directly from your terminal.

## Commands

| Command | Description |
|---|---|
| `memo add "text"` | Add a memo |
| `memo list` | List all memos |
| `memo pop` | Remove the newest memo |
| `memo rm <id>` | Remove a memo by ID |

## Storage

Memos are stored locally in `~/.memocli/global.json`.
